## 0.1 原型实装与验收修订

| 修改 | 原因与取舍 | 验证 |
|---|---|---|
| 战斗上限设75秒 | 给低阶、控制和召唤构筑留下完成技能循环的余量；不改变超时撤退/首领失败边界 | 最终3216场真实战斗，另低操作30局有4次超时失败 |
| 所得遗物先保留于收藏，未装备不生效 | 满槽领奖不应丢奖或让流程卡住；更换仍受节点/战斗锁定 | 装备/满库/奖励回归与三次完整UI战役 |
| M13新兵护盾在实际部署时取前两名 | 防止未上阵或被吸收的新兵抢占配额 | 经营专项回归 |
| 未消耗I01/I02预备在开战时释放 | 玩家不追加拉杆时不应无声占用战内道具额度；库存不扣 | 经营专项与取消预备UI |
| 冻结暂停未发射蓄力及瞄准 | 玩家预期控制能阻止正在准备的攻击；已经飞出的伤害不凭空撤回 | 冻结对照与33项战斗回归 |
| 净骨审判官优先临时召唤、弩手每第三发优先射程内后排、火油手选密集落点 | 让既有敌人形成可读应对，不提高基础血量/伤害；继续受嘲讽、射程和预警限制 | 180场固定军团前后对照及最终90局 |
| 第三章后段普通双雷矛、精英轻火力或双雷矛变体 | 分别考验法术承伤、后排处理和分散；替换重甲后总HP下降，避免血量拖时 | 600场组合提案、89次最终遭遇覆盖 |
| 敌方周身/穿刺范围说明与实际机制一致 | 旧GDD对部分技能写“后方/前方”，与实装全向邻近或更大范围不同；以游戏敌情中明确展示的版本为准 | `docs/COMBAT_PLAYABILITY_REVIEW.md` |

最后合并的规则与内容哈希见 `artifacts/balance/shipping-30.json`。最优策略89/90通关，固定4位且不投资的简化策略0/30通关；两者只能形成机制压力的上下界，不能代替真实玩家胜率。未因看到毒疗胜率高就直接削弱尸毒：对照发现强势主要来自高阶身体、权重投资和续航，毒跳只占部分输出。
