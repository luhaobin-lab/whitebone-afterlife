# 中后期遭遇组合：有界提案与对照

本提案已经采纳并落实到`campaignMap.ts`：仅第三章第五层末波，普通节点用双雷矛替换两名禁卫；精英节点按既有节点seed奇偶，在轻火力侧翼和双雷矛精英之间互斥选择。预览列出实际敌人数和应对提示。所有替换都降低总HP和入场盾，不增加随机抽样，也不依据玩家流派切换。下文600场是采纳前的隔离提案证据；最终合并目标选择规则后的完整远征结果见`BALANCE_REPORT.md`。

## 方法与边界

- 共600场隔离战斗：首轮三候选360场，再分别补轻火力侧翼120场、普通双雷矛120场。
- 每个方案使用三种策略各10组在`cadence-30.json`中实际到达对应章节第5层第3波的军团。职业、经验、专精和人数固定；每队测试原站位与左右镜像两种合法站位；每种站位分别跑原组合与候选。每个表格单元是20场均值。
- 两组均统一不带遗物和消耗品，以隔离敌方组合。它们是离线固定输入对照，不能冒充完整远征胜率；采用方案后还需用合法经营策略重新跑完整90局。
- 同一配对使用同一随机种子，生命/攻击倍率同为1.08，时间上限75秒，未改变敌方模板数值、掉落、价格或玩家等级。
- 每份JSON记录候选前后人数、基础HP、基础普攻DPS、每场队伍和结果；各实验源码运行前后hash相同。战斗引擎为7744c75d版。world.json期间仅由战斗代理对齐文字，未由本实验改动。
- “敌方实际伤害”是敌方单位累计造成的实际HP伤害，包含对临时兵伤害；“战末HP”只统计永久兵剩余HP占最大HP比例；临时兵受击记录是事件次数，不是伤害值。所有600场均获胜，证明没有在此样本中制造失败墙，也意味着这只是适度压力增强。

## 推荐范围

| 方案 | 仅改变的位置 | 原阵容 → 候选阵容 | 人数 | 基础HP | 主要应对 |
|---|---|---|---:|---:|---|
| 1. 普通雷矛分队 | A3 / L5 / normal / W3 | E11×3 + E12 + E13 → E11 + E12 + E13 + E14×2 | 5→5 | 1620→1520（−6.2%） | 留支援距离，错开核心与承伤位；机动单位仍较快清理 |
| 2. 精英轻火力侧翼 | A3 / L5 / elite / W3 | E11×3 + E12×2 + E13 → E11 + E12×2 + E13 + E07×2 + E09×2 | 6→8 | 1880→1820（−3.2%） | 范围清轻单位，机动切远程；慢速召唤阵需关注火油落点 |
| 3. 精英双雷矛（备选） | 同方案2位置，与方案2互斥 | E11×3 + E12×2 + E13 → E11 + E12×2 + E13 + E14×2 | 6→6 | 1880→1780（−5.3%） | 更明显的双目标法术承伤测试 |

三种替换都减少两名禁卫，因此还减少160点入场盾，避免把总有效生命偷偷抬高。只在上述明确末波应用，不影响第1章、第2章、Boss，或把整个第三章全面加压。第三条如采用，应在地图/侦察中作为独立明示配置，不能在同一波再叠轻火力侧翼。

## 已淘汰的直觉方案

- A2晚精英仅将一名戟兵换为火油（6人，HP1185→1125）：均衡/骑兵受到的总伤害反而下降，毒疗只增加约1.2%。单靠多放一个E09不足以产生稳定压力；需等战斗代理对落点目标选择的独立证据。
- A3双祭司射阵（5人，HP1620→1440）：三种构筑都更轻松，敌伤下降约16%–17%，均衡平均倒地0.30→0.10。新增治疗没有弥补前线不足，故不建议用它解决后期压力。

## 呈现与后续验证

侦察必须显示具体敌人数量及威胁：雷矛分队标注“双目标法术，错开核心与前排”，轻火力侧翼标注“轻远程增多，火油落点提前1秒显示”。玩家应在选路前看见差异；不能依据玩家当前流派偷偷换克制阵容。若在同层同时有两个精英分支，可以用公开种子固定两种配置，让玩家选择。

这些隔离结果支持小范围试用，不能宣称已修复后期停滞或已形成真实玩家的成功反制。合并后已安排三策略各30种子、跨章节和存档回归；UI实机仍需验证侦察、布阵、火油预告和战报是否让玩家看懂原因。

```sh
npm run balance -- --probe-encounters --seeds 10 --recipe A3-normal-lightning --out artifacts/balance/encounter-normal-lightning-120.json
npm run balance -- --probe-encounters --seeds 10 --recipe A3-light-flanks --out artifacts/balance/encounter-light-flanks-120.json
```
