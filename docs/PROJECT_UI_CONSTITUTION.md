# 项目UI宪法 v0.1

## 任务与玩家路径
PC横版2D亡灵军团经营。鼠标为主，中文。首选1440×900，最低1280×720；窄屏改纵向滚动，不缩成看不清的桌面截图。首局目标路径：选择起手→地图出征→免费拉杆→可选改盘→收兵→部署/献祭→开战→战报→下一波→据点奖励→地图。每阶段只突出一个主要动作。

S0为命匣危急、资金不足、不可逆献祭预览；S1为当前波、下一步和拉杆/收兵/进攻；S2为敌情、单位对比、概率与协同；S3图鉴、完整词条、统计置于抽屉；S4氛围不遮文字。无需看图鉴也能完成首波。

## 视觉与令牌
阴间招工站、旧木招魂机、骨白纸签、褪色绿铜。背景用有层次的灰青夜景，战场生命条与单位轮廓优先。拒绝SaaS统计卡片墙、无意义英文标签和所有信息同时展开。

- 字体：中文Noto Sans SC优先、系统sans-serif回退；英文与数字同族。字重400/600/800。
- 六档字号：12说明、14辅助、16正文、20分区、24标题、32大奖；不得增加第七档。大封面字按32档整体图形化缩放，正文不变。
- 间距4/8/12/16/24/32；外边距24（窄屏12），按钮高度44，圆角4/8/12。
- 功能色：主要操作#d9aa59，成功#7ec8a1，危险#e17669，信息#83aec5；文本#f0e5cf，次文本#b4b8a8；背景#121b19，表面#1b2925、#263932，细边#415148。家庭符号用固定骨白/腐绿/锈红/浅紫/青蓝/赭金，只用于识别，不代替按钮语义。
- 至多两层容器；主要操作使用实色暖金，次操作暗面描边，危险按钮只用于献祭/放弃/重开。

## 界面契约
- 标题：选择新远征或继续存档；介绍一句话、三个起手方向与目标时长，规则按需展开。
- 地图：选择下一个已连接节点，明确敌情、风险和奖励；将来节点可查看不可误进。
- 准备：战场预览上方，招魂机与军队工作台下方。当前重点在拉杆→收兵→进攻逐段迁移。出兵暂存不丢奖。
- 战斗：收起经营大面板，让战场成为唯一中心；仅保留命匣/波次/速度/暂停和单位简要状态。
- 结算：显示胜负、骨头来源、伤害/治疗/召唤/关键协同，主要按钮进入下一波或领奖。
- 服务：只展示当前地点的库存或选项，费用和所得同组，永远可离开；不出现老虎机。
- 单位详情：名称/职业/训练/定位先读，技能和专精再读，献祭或换壳预览中明确消失者和结果。

## 组件状态
每按钮具备默认、悬浮、焦点、按下、禁用并说明原因；空背包、满员、无钱、无目标、满级、锁定节点均明确。抽取中锁按钮但不锁暂停；收兵只一次。危险动作需要明确预览，可取消。拖放布阵另提供点单位→点格子的替代操作。

## 动效与音效
界面高频过渡120–180ms；拉杆总动画约700ms，中奖额外500ms可加速；大奖最多1000ms，不反复挡流程。战场命中闪白、数字、冲锋残影、治疗绿弧、尸骸衰减均反映真实事件。静音与减少动画开关始终可达。

## 验证门槛
去装饰仍能完成首波；灰度下按钮主次明确；1280×720/1440×900/窄屏无关键遮挡；长名称和全部8名上阵不溢出；每个状态截图和点击路径实测。专业自检分数至少85且无阻断项，真人未验收不声称已验证好玩。
